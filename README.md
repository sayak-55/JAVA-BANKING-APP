📌 Project Overview
Bank Management System (Console-Based Java App) is a menu-driven application that simulates basic banking operations in a console environment. Users can create accounts, deposit and withdraw money, view account details, and delete accounts. It uses Java's object-oriented features and handles user inputs through the command line.

🖥️ Sample Output Screenshot

🧰 Features
Create a new account (with auto-generated account number)

Choose account type (Savings/Current)

Input customer details (Name, Phone, Initial Balance)

Perform operations:

Deposit money

Withdraw money

View account details

Delete an account

Display timestamps of account creation

⚠️ Confirmation Prompt: Before deleting an account, the app clearly asks for user confirmation (Stay/Delete) — preventing accidental deletions.

✅ Success Message: After valid input, the app confirms account deletion with a timestamp, showing proper tracking and feedback to the user.

🕓 Real-Time Logging: Use of real-time system date and time adds professionalism and helps in record-keeping.
